# App Scholar

## Sobre o projeto
O projeto consiste em um aplicativo de gerenciamento escolar para acessar/criar/excluir o registro de Alunos,Professores,Coordenadores,ETC.
## Funcionalidades
- Visualizar e revisar pastas de alunos e professores;
- Modificar as principais informações das pessoas registradas;
- Excluir ou inativar arquivos antigos
## Tecnologias utilizadas
- Snack: Aplicativo utilizado como base de programação para o Front-End e Back-End.
- BrModelo: Utilizado para a criação da base do banco de dados do aplicativo.
- Xampp: Utilizado para criar,acessar e modificar o banco de dados.
## Estrutura do projeto
Pages é a pagina para as paginas e modelos de cada uma das paginas como Homepage,Alunos,Etc
Assets é os arquivos de imagens e detalhes do projeto
Components é a base do aplicativo á base do Snack
App.Js é o aplicativo em si, com ele você consegue acessar todo o projeto
## Como executar
Basta apenas baixar todos os arquivos da Pasta **app-scholar-v1** e depois iniciar a arquivo _App.Js_
